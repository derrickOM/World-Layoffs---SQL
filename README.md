World Layoffs Analysis Using MySQL

Project Overview
This project explores and analyses layoff data using MySQL.

Tools Used
-MySQL
-MySQL Workbench
-Github
-SQL

Project Workflow
1. Imported the original csv dataset into MySQL.
2. Created separate table to preserve original data.
3. Performed data cleaning using various SQL queries involving Window functions, CTEs and JOINs on the separate table.
4. Explored and analyzed the dataset using various SQL queries involving aggregate functions and CTEs.

Project Files
-layoffs.csv
-world_layoffs_database.sql
-data_cleaning.sql
-exploratory_data_analysis.sql

Key Findings
-Biggest number and percentage of layoffs
-Companies that were essentially closed
-Timeline of the layoffs
-Industries affected in order of magnitude
-Countries affected in order
-Layoffs per year

Reproducibility
The original dataset, SQL scripts and database export are provided to help others understand and recreate the project.
